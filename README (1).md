# FlowBoard — Project Management

A fully client-side project management app built with vanilla HTML, CSS, and JavaScript.

## Features

- 🔐 Login & registration (in-memory)
- 📊 Dashboard with stats and activity
- 📁 Projects with Kanban boards
- 🗂️ Drag-and-drop task cards
- 💬 Task comments and assignees
- 🔔 Notifications
- 👥 Team members view
- 📱 Mobile responsive with slide-in sidebar

## Deployment

### GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch**, select `main` and `/ (root)`
4. Save — your site will be live at the URL above in ~60 seconds

### Local

Open `flowboard.html` directly in any browser. No server needed.

## Tech

Vanilla HTML/CSS/JavaScript — zero dependencies, zero build tools. All data is in-memory and resets on page refresh.
