# Pulse — Social

A fully client-side social media demo app built with vanilla HTML, CSS, and JavaScript.

## Features

- 🔐 Login & registration (in-memory, no backend required)
- 🏠 Home feed with post composition
- 🔍 Explore & search users
- 🔔 Notifications (likes, comments, follows)
- 👤 User profiles with follow/unfollow
- 💬 Comments on posts
- ✏️ Edit your own profile

## Deployment

This app is a single `index.html` file with no build step or dependencies.

### GitHub Pages (recommended)

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch**, select `main` and `/ (root)`
4. Save — your site will be live in ~60 seconds

### Local

Just open `index.html` in any browser. No server needed.

## Tech

- Vanilla HTML/CSS/JavaScript — zero dependencies, zero build tools
- All data is stored in-memory; refreshing the page resets to demo data
